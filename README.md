# Trade CRM Skill

用自然语言维护本地 Markdown 外贸客户、询价和订单资料，适用于卡册、卡套、卡膜等外贸业务。

你可以直接描述操作，也可以提供阿里巴巴聊天截图、报价单、生产单等材料。**模型负责读取和理解材料，Skill 负责业务流程、记录规则和需要用户决策的边界。** 信息清楚时执行维护；意图、归属或内容取舍不明确时，先给出依据和建议，再由你决定。

本项目为纯指令与模板包，不包含 OCR、文件解析器、运行脚本、数据库或模型接口。客户资料由每位业务员自行选择本地目录保存，可通过 Obsidian 阅读和编辑。

## 能做什么

| 场景 | 示例 |
|---|---|
| 客户建档和资料更新 | 新建客户，ID 是 123，德国，Alex |
| 从询价开始维护订单 | 客户 123 有一笔新的卡册询价，帮我建立记录 |
| 补充产品、包装和物流信息 | 客户 123 的 R-001 需要独立包装 |
| 保存各版报价和重要变更 | 追加第二版报价，第一版保留 |
| 查询资料和维护状态 | 查一下 R-001 的报价和箱规；这笔订单已经成交 |
| 结合材料判断操作 | 这是客户的聊天和报价文件，结合本地记录判断该新建还是更新 |

客户使用用户提供的数字 ID。每个客户的订单分别从 `R-001` 递增；同一笔业务从询价到成交沿用同一订单号。详细规则见 [Skill 入口](skills/trade-crm/SKILL.md)。

## 安装后的简单示例

### 1. 选定自己的资料目录

```text
使用 $trade-crm。我要维护本地客户资料，请先帮我确定资料库存放位置。
```

告诉 Agent 你自己的资料库根目录。如果还没有资料库，明确要求在选定位置新建。没有指定目录时，Skill 会先询问，不默认使用当前目录、技能目录或开发者电脑上的目录。

同一会话复用已选资料库；切换资料库时重新定位客户和订单。新会话没有明确选库上下文时会再次询问，不将个人路径写回技能包。

### 2. 建立客户与询价

```text
使用 $trade-crm，新建客户，ID 是 123，德国，Alex。
```

```text
客户 123 有一笔新的卡册询价，帮我建立记录。数量 1,000 个，需要印 LOGO，其他信息待补充。
```

目标明确且无冲突时建立记录，首笔询价分配 `R-001`，并维护客户文档的订单摘要和链接。

### 3. 提供材料，让模型判断业务操作

附上聊天截图和相关文件，再发送：

```text
这是客户 123 的阿里巴巴聊天截图和报价文件，请结合本地记录，判断是新询价还是原订单的补充。需要我决定的地方先给出依据和建议，不要自行覆盖有冲突的信息。
```

### 4. 更新和查询

```text
客户 123 的 R-001 需要独立包装。请更新记录。
```

```text
给客户 123 的 R-001 追加第二版报价：USD 0.95/个，适用数量 1,000 个，待客户确认；第一版保留。
```

```text
查一下客户 123 的 R-001 当前报价、箱规和待确认事项。
```

仅阅读或翻译材料不会自动写入 CRM。更多交互示例见 [操作示例](skills/trade-crm/references/examples.md)。

## 业务资料结构

业务资料库由业务员自行选定，位于技能安装目录和本仓库之外。以下名称和客户仅为格式示例，不是随包提供的业务数据。

```text
选定的资料库根目录/
├── 模板.md
└── 123-德国-Alex/
    ├── 客户.md
    ├── R-001.md
    └── R-001/
        ├── 报价-v1.xlsx
        └── 设计稿.pdf
```

本地 `模板.md` 优先；缺少时使用包内模板。订单保存详细过程，客户文档保存摘要和链接，避免重复维护完整内容。

## 使用边界与验证

- 不实现删除；不自动录入或同步外部业务系统，不依赖特定外部技能。
- Git 和 Obsidian 同步由业务员原有流程负责，Skill 不执行这些操作。
- 不提供并发写入或事务服务；同一笔业务按串行方式维护。
- 无法确定客户、订单、报价版本，或材料与现有记录有实质冲突时，先询问。明确要求新增报价版本时，正常追加，不把所有变化都当作冲突。
- 不包含开发者的绝对路径、固定时区或个人运行配置。日期采用用户指定或宿主提供的会话时区。

已完成的结构、资料维护演练、便携性检查及未实测部分见 [验证记录](docs/validation.md)。文件安装与宿主加载是两个不同状态，README 的安装提示词要求分别说明，不承诺在所有 Agent 中自动生效。
