# 操作示例

示例中的 ID、材料及业务值只是说明，实际操作以用户提供的信息和本地记录为准。

## 首次选库与切换

- 首次说“新建客户，ID 123，德国，Alex”，但没有选库上下文：先询问客户资料存放的根目录，不默认使用当前工作目录、技能目录或开发者机器上的位置。
- 用户明确指定一个存在且可访问的根目录：简要说明选定目录，再执行请求；本会话后续业务复用该目录。
- 用户给出不存在的路径，但只要求查询：说明路径不存在，请用户检查，不创建资料库。
- 用户明确说“在指定位置新建资料库并建档”：核对路径及权限后，在已授权范围内初始化，不重复询问相同创建决定。
- 用户说“换到另一个业务员的资料库”：要求明确目标根目录并核对访问权限，重新检索客户及订单；即使新库也有客户 123，也不沿用旧库订单归属。
- 用户给出相对路径但宿主没有可靠工作目录：询问绝对路径，不按技能安装位置猜测。
- 新会话只有相同的客户 ID：没有已确定资料库时先选库，不能承诺从上次会话记住位置。
- 用户只说“翻译这张截图”：直接处理阅读任务，不询问资料库、不写入 CRM。

下列业务维护示例均以已明确选库为前提；目录未确定时先完成选库。

## 明确的自然语言请求

| 用户表达 | 处理与结果 |
|---|---|
| 新建客户，ID 是 123，德国，Alex。 | 检查 ID 无冲突后，建立 `123-德国-Alex/客户.md`；其他未知资料待补充，订单表不放占位订单 |
| 给客户 123 补充联系电话。 | 未给号码且材料中也无明确号码时，询问具体号码，不写入猜测值 |
| 客户 123 的电话补充为 +49 30 123456，原来没有。 | 读取最新客户文档，填写联系方式和最近更新，保留其他内容 |
| 客户 123 有一笔新的卡册询价，帮我建立记录。 | 分配该客户下一订单号，建立订单文档与附件目录，在客户文档加入摘要行 |
| 客户 123 的 R-001 需要独立包装。 | 更新包装章节及相关摘要、日期，不自动增加报价或确认成交 |
| 给 R-001 记录第二版报价，第一版保留。 | 有明确当前客户上下文且提供了第二版内容时追加；多个候选或缺少报价内容时先问 |
| 查一下客户 123 的 R-001 报价和箱规。 | 从订单原文相应章节回答，区分各版报价和未确认内容，给出来源，不修改资料 |
| 客户 123 的 R-001 已经成交。 | 同步订单及客户目录状态、日期，编号与附件目录保持不变 |

## 截图和文件驱动

### 上下文已经明确

上文：“接下来更新客户 123 的 R-001。”

用户发送聊天截图和报价单：“这次报价定了，按这份补充进去，旧版留着。”

模型理解材料后读取本地订单。若最终确认、版本及业务内容清楚且无未解释冲突，追加报价、记录确认依据，维护摘要；归档属于这次任务且有可复制原件时复制附件。此时不重复询问“是否更新”。

### 只有材料，没有用途

用户发送几张阿里巴巴聊天截图和一个报价文件，没有其他说明；此前没有当前客户或业务上下文。

先只读整理并检索本地候选。例如：“材料中的公司与客户 123 接近，但还不能确定是 R-001 的后续沟通还是新询价。建议先确认业务归属。你希望补充到 R-001，还是建立一笔新询价？”等待决定，不先建单再询问。

### 新客户缺少 ID

用户：“这是德国 Alex 的聊天，帮我建档。”

未查到相符客户，用户也未提供 ID。说明未查到的结果，请用户提供数字 ID；不能用阿里巴巴账号、联系电话或自动生成数字代替用户指定 ID。

### 客户明确，订单不明确

客户 123 已有两笔卡册业务，材料没有本系统订单号。

列出两笔订单的编号、摘要及相关差别，询问补充哪一笔或新建一笔。同产品、同数量或同一天不自动视为同一订单。

### 材料与本地记录冲突

R-001 记载 1,000 个，聊天出现 2,000 个，生产单仍为 1,000 个，均无明确确认变更说明。

列出差异和来源，建议先列为待确认，请用户决定采用值或暂缓；等待期间不改订单数量，不以生产单或最近上传的截图自动覆盖其他记录。

### 文件名相同

订单附件目录已存在 `报价单.xlsx`，用户又提供同名文件要求归档。

说明目标已存在，建议如用户确认是新版则另存 `报价-v2.xlsx`，请用户决定。未决定前不复制覆盖，不自行判定两个文件相同。

### 材料无法读取

用户要求按截图更新单价，但数字模糊。

说明具体单价无法辨认，询问明确单价或是否暂缓该项。可以继续整理可读信息，不假称完成单价更新。

## 范围边界

- “翻译这张阿里巴巴聊天截图”：只翻译，不创建、归档或修改 CRM 记录。
- “这份生产单写了什么”：只阅读和回答，不推断成交状态或自动写库。
- “帮我开发一个 CRM 页面”：属于软件开发，不由本技能接管。
- “把客户 123 的 R-001 录入 HS”：说明需用户另行选择其环境中可用的外部系统录入工具或流程并指定资料，不依赖固定技能名称，不自动调用或写入 HS。
- “删除 R-002”：说明本技能不实现删除，不执行文件操作。

## 用户手工编辑和部分失败

已有订单新增了“客户特殊备注”章节。补充包装要求时局部修改相关章节，保留特殊备注；客户订单表只同步对应行。

若订单已写入但客户文档写入失败，报告实际状态：“R-001 的包装要求已更新；客户订单目录尚未同步，当前仍是旧日期。”说明原因和补齐建议，等待用户决定，不宣称全部完成、不删除订单重做。
